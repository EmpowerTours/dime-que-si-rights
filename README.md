## Note on content matching

"Dime Que Si" may match other recordings that use the same licensed instrumental. This is
expected: the instrumental was licensed on a **non-exclusive** basis, so multiple artists
write and record their own separate songs over the same backing track.

One such recording is "Mona Lisa" by YKSPYDA (1:52, released 2025). "Dime Que Si" is a
distinct work — 2:19, with original lyrics, melody and vocal performance written and recorded
by Earvin Gallardo in 2026. The only element the recordings share is the licensed
instrumental. Neither artist claims any right in the other's recording.

Because the instrumental is non-exclusive, this release is **not** submitted to content
identification systems, and Content Recognition stores (YouTube Content ID, Facebook,
Instagram, TikTok) are deselected for this release.
